# Roxanne's Portfolio

A personal portfolio website showcasing my background, technical skills, and selected projects in web development and UI/UX design.

## Features

- **Home Page** – A themed landing page introducing the portfolio, presenting a character representative of myself (an otter).
- **Interactive Navigation** – A hash-based navigation system for switching between website sections.
- **About Section** – Presents my background, technical stack, and personal story through an interactive book-inspired layout.
- **Project Showcase** – Displays selected projects with descriptions, technologies, and project details.
- **Project Gallery** – Allows visitors to view additional project images through an interactive photo viewer.
- **Responsive Design** – Adapts the layout to different screen sizes and devices.
- **Custom Visual Design** – Features an ocean-inspired color palette, otter illustrations, wave effects, and themed interface elements.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Design and Development

The website was designed and developed with a focus on visual consistency, user experience, and responsive interface design.

Figma was used for UI/UX design and layout planning, while HTML, CSS, and JavaScript were used to implement the website's structure, styling, and interactive functionality.
